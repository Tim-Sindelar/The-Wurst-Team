Popups

Two kinds only. Decisions use bottom sheets; routine confirmations stay in the page. Urgent banners appear below the header. Closing a sheet any way except its right-hand button counts as Cancel.

Decision sheet

Two equal buttons. Left is the safe option, right is the action (red outline when risky). Labels are verbs.

Notification banner

Urgent ones (check-in reminder, seat lost, session end) stay until dismissed.

Bottom navigation

Home Map Friends Profile

Home / Map / Friends / Profile appear in production and PRs. Explicitly disabling social hides Friends. Keep this bar outside the scrolling content, below page actions. Profile replaces the avatar shortcut on Home.

Camera view

Dark in both themes, because it is a camera. The scan line animates with a calm loop and stops when the phone has reduce-motion on.
